# Ankit Deo | Portfolio

Personal portfolio of Ankit Deo, a Computer Engineering student from Nepal.

- Live: https://ankitdeo.com.np
- GitHub: https://github.com/AnkitDeoOfficial

Built with plain HTML, CSS and JavaScript. Project data is stored in Supabase.

## Files

- `index.html`: the whole website
- `assets/`: images used by the site
- `supabase-setup.sql`: database setup for Supabase

## Deploy on GitHub Pages

1. Create a repository named `AnkitDeoOfficial.github.io`.
2. Upload all files and the `assets` folder.
3. In the repository, open Settings > Pages and choose the `main` branch, root folder.
4. The site goes live at `https://ankitdeoofficial.github.io`.
